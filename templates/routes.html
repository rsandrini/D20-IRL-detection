Local Roll API No auth

MethodPathBody / ParamsDescription
POST /api/roll mode = normal | advantage | disadvantage (default: normal)
debug = any value → generate GIF 		Roll the die and detect the result.
Response example 
{
  "roll_id": "uuid",
  "mode": "normal",
  "detections": [
    {"face": 15, "confidence": 0.87, "bbox": [x1, y1, x2, y2]}
  ],
  "selected": {"face": 15, "confidence": 0.87, "bbox": [...]},
  "image": "static/results/uuid_crop.jpg",
  "gif":   "static/results/uuid.gif",
  "time_elapsed": 2.45,
  "time_elapsed_detection": 0.18
}
Error responses 
429 {"error": "roll_in_progress"}
422 {"error": "could_not_detect_two_dice", "detections": [...]}
POST /api/roll/<roll_id>/report JSON body: {"correct_face": 15} Report a wrong detection result. Updates DB for retraining.
Response 
200 {"status": "ok"}
400 {"error": "correct_face required"}
404 {"error": "roll not found"}

User Roll API Bearer token

Pass Authorization: Bearer <token> header. Token is shown once at user creation.

MethodPathBody / ParamsDescription
POST /u/<username>/roll Same as /api/roll — mode, debug Roll for a specific user. Enforces enabled flag and daily_limit.
Error responses 
401 {"error": "missing_token" | "invalid_token"}
403 {"error": "user_disabled"}
403 {"error": "daily_limit_reached", "limit": 10, "used": 10}
429 {"error": "roll_in_progress"}
GET /u/<username>/history Query: limit (default 20) Returns the last N rolls for that user as a JSON array.

User Management No auth

MethodPathBodyDescription
GET /api/users — List all users.
POST /api/users {"id": "alice", "daily_limit": 10} Create a user. Returns token (shown only once).
Response 
201 {"id": "alice", "token": "<32-char hex>", "daily_limit": 10}
409 {"error": "user already exists"}
GET /api/users/<username> — Get user info + today's roll count.
PUT /api/users/<username> {"enabled": false, "daily_limit": 20} Update user enabled state or daily limit.
